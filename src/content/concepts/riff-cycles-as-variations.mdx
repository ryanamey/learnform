## Your riff is a theme

A riff that repeats for minutes, with the band changing around it, is the same problem Classical composers faced in **variation form**: one theme, many statements, and the risk of monotony. Belkin's chapter on variations reads almost like advice for a riff-based band <Source book="belkin" where="Ch. 10 Variation form" />.

The theme first. A good theme for variations is **simple and memorable**: a clear skeleton the ear can track under any surface. An eccentric, complicated theme repeated many times becomes irritating. For a riff cycle that means: the odd meter or the strange grouping can be the riff's identity, but the shape has to be learnable, so the changes around it read as changes.

<KeyIdea>Keep the riff's skeleton fixed and change everything around it. Then organize the changes so they make a larger shape.</KeyIdea>

## Five rules from variation form

1. **One character per variation.** Each statement (or block of statements) has a stable character built on one or two motives. Mood changes *between* variations, not inside them.
2. **Group the variations.** Periodicity is the enemy. Organize variations into groups that make larger progressions: three getting faster, then two slow; growing density; harmony getting darker. Brahms's *Handel Variations* pairs and groups 25 variations this way.
3. **Move the climax.** If the theme's peak comes early in the cycle, let later variations push it later, eventually to the end. Belkin's Beethoven Op. 135 example shifts the climax from variation to variation.
4. **Change mode for instant colour.** The Classical “minore” variation (major theme in minor) is a sudden new colour with the same skeleton. For a band: the same riff with a new chord underneath, or the same riff a tritone away.
5. **The last variation breaks the pattern.** It's longer, more complex, ends with an elaborate cadence, or changes form entirely (a fugue). It must feel unique and culminating, not just the next one.

Two more points: with a **short** theme, variations can run **continuously** without stops to avoid stop-and-go (Beethoven Op. 135); and **ornamental** variations knit a new motive around the theme's outline, which is exactly what a guitar does when it plays new figures over a fixed bass riff.

## One-part forms: no contrast, so build

Belkin's chapter on one-part forms covers pieces built on one idea with no strong internal punctuation <Source book="belkin" where="Ch. 7" />. Without contrast, the piece has to **build a progression to a climax**, usually near the end, and then complete its emotional trajectory. His Rachmaninoff example uses several gradually intensifying **waves**, each climax higher than the last, with the widest registral spread at the main climax, then thinning. That's a template for a long riff-based piece with no chorus.

## A riff-cycle plan

<Steps>

1. Write the riff's skeleton: what never changes (the rhythm and grouping, usually).
2. List what can change around it: drum feel, cymbal, guitar sound, register, harmony underneath, counter-lines, vocal.
3. Plan statements in **groups** (for example 3 + 3 + 2), each group with its own character and direction.
4. Decide where the peak of the cycle sits in each group, and move it later as the piece goes.
5. Design the last group to break the pattern.

</Steps>

<ListenerSide grade="moderate">

Margulis's work (Module 5) suggests repetition is what lets listeners shift attention to new aspects of the music and participate, so a fixed skeleton isn't a weakness. Belkin's warning about monotony is the other half: habituation sets in when nothing at a higher level is moving. The grouping rules are craft, not measured findings; the listening test is where you check whether your groups are heard as groups.

</ListenerSide>

## Practice

<Exercise title="Eight statements of one riff">

1. Take one riff and write eight statements of it without changing its skeleton.
2. Organize them in groups (3 + 3 + 2 or 2 + 2 + 4) with a different character per group.
3. Move the peak of the cycle later in the second group.
4. Make the last statement break the pattern.
5. Play the plan with a drum loop and listen for the groups.

</Exercise>

<ApplyIt>

Find a riff that repeats many times in one song. Write its statements as a variation plan: groups, the character of each group, where the peak sits, and how the last statement breaks the pattern.

</ApplyIt>
